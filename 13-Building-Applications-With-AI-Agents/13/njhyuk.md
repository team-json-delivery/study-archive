# Chapter 13. Humans and Agents (인간과 에이전트)

## 1. 왜 인간-에이전트 관계가 중요한가
- 에이전트는 결국 **사람을 위해, 사람과 함께** 일한다. 기술적 완성도만큼 **신뢰·윤리·책임**이 중요.
- 자율성이 커질수록 잘못된 판단의 사회적 파장도 커짐 → **사람의 감독과 가치 정렬**이 필수
- 이 장의 범위: 윤리 원칙 → 신뢰/감독 구축 → 편향 → 책임·규제
- 책의 마무리 장: "어떻게 하면 에이전트를 **안전하고 신뢰할 수 있게** 사람 사회에 통합할까"

## 2. 윤리 원칙 (Ethical Principles)

### 2-1. 감독 (Oversight)
- 사람이 에이전트를 **감독·개입·중단**할 수 있어야 함 (human-in/​on-the-loop)
- 고위험 결정은 사람 승인, 언제든 멈출 수 있는 **정지 장치(kill switch)**

### 2-2. 투명성 (Transparency)
- 사용자가 **AI와 상호작용 중임을 알 수 있게** 하고, 무엇을 어떻게 하는지 공개
- 데이터 사용·한계·불확실성을 숨기지 않음

### 2-3. 공정성 (Fairness)
- 특정 집단에 **불리하거나 차별적 결과**를 내지 않도록
- 데이터·모델·결과 전반에서 형평성 점검

### 2-4. 설명가능성 (Explainability)
- 에이전트가 **왜 그런 결정을 했는지** 사람이 이해할 수 있어야 함
- 근거·출처 제시, 추론 과정 추적 가능성

### 2-5. 프라이버시 (Privacy)
- 개인정보 최소 수집·보호, 동의 기반 사용 (12장 데이터 보호와 연결)

## 3. 신뢰와 감독 구축 (Building Trust & Oversight)
- 신뢰는 한 번에 생기지 않음 → **일관되고 예측 가능한 동작**으로 쌓인다.
- 신뢰 구축 요소
  - **적절한 자율성 수준**: 위험도에 따라 자동화 정도를 조절
  - **에스컬레이션**: 확신이 낮거나 고위험이면 사람에게 넘김
  - **피드백 경로**: 사용자가 잘못을 지적·수정할 수 있게
  - **일관성·신뢰성**: 같은 상황에 같은 품질
- 과신(over-trust)도 위험 → 사용자가 **AI 한계를 알도록** 안내

## 4. 편향 다루기 (Addressing Bias)
- 편향의 출처: **학습 데이터, 모델, 설계, 사용 맥락**
- 대응
  - 데이터 다양성·대표성 점검, 편향 측정 지표
  - 결과 감사(audit), 하위 집단별 성능 비교
  - 완화 기법 적용 후 **재검증** (완화가 새 편향을 만들 수도 있음)
- 편향은 **완전 제거보다 지속 관리**의 대상

## 5. 책임과 규제 (Accountability & Regulatory)
- **책임 소재(accountability)**: 에이전트가 잘못했을 때 누가 책임지는가를 명확히
- 감사 로그·의사결정 기록으로 **추적성(traceability)** 확보
- 규제 준수: 지역·산업별 AI/데이터 규정(예: EU AI Act, GDPR 등)
- 사고 대응(incident response)과 구제 절차(사용자 이의제기·시정)

## 6. 핵심 정리 (Key Takeaways)
1. 에이전트는 사람과 함께 일하므로 **윤리·신뢰·책임**이 기술만큼 중요.
2. 윤리 5원칙: **감독 · 투명성 · 공정성 · 설명가능성 · 프라이버시**.
3. 신뢰는 **일관성 + 적절한 자율성 + 에스컬레이션 + 피드백**으로 쌓이며, 과신도 경계.
4. 편향은 데이터·모델·맥락에서 나오며 **측정→완화→재검증**의 지속 관리 대상.
5. **책임 소재·추적성·규제 준수**를 갖춰야 사회에 안전하게 통합된다.

| 주제 | 핵심 |
|---|---|
| 윤리 원칙 | 감독·투명성·공정성·설명가능성·프라이버시 |
| 신뢰 구축 | 일관성·적절한 자율성·에스컬레이션·피드백 |
| 편향 | 출처 파악 → 측정 → 완화 → 재검증(지속 관리) |
| 책임·규제 | 책임 소재·추적성·규제 준수·사고 대응 |
