# 16. 결국 모든 협상은 둘로 나뉜다
- 이익 중심의 협상 vs 관계 중심의 협상
  - 관계와 이익은 반비례 -> 나의 이익을 추구하다 보면 관계가 나빠지기 마련
  - 상대와의 지속성으로 관계 또는 이익 중심의 협상인지 알수 있음
    - 상대를 앞으로도 계속 봐야 한다면, 관계 중심의 협상
- `뛰어난 협상가란 이익 중심으로 만난 사람을 관계 중심으로 바꿀 수 있는 사람`
- 관계 중심의 협상에선 에임 하이 하지 말라고 함
  - 터무니 없는 에임 하이는 상대와의 신뢰를 훼손할 수 있음
- 관계 중심의 협상에선 단기간의 경제적 이익보다 신뢰나 평판이라는 오래가는 가치가 훨씬더 중요

# 17. 협상 테이블에서 해선 안될 세 가지 행동
- 협상에서 하지 말아야할 것
  - 감정의 언어가 아닌 판단의 언어를 쓰는 것
    - '상대의 언론 플레이에 피가 거꾸로 솟음' vs '상대편은 겉과 속이 완전히 다른 사람' -> 후자가 더 안좋은 표현
    - 상대에 대해서 판단하지 말고, 내 감정을 표현하는게 나음 -> 상대를 낙인 찍는건 매우 불쾌한 경험
    - 감정을 쓰면 내가 원하는 메시지를 전달하면서도 상대와의 관계가 단절되는 걸 막을 수 있음
  - 협상 테이블에서 '귓속말'을 하는 것
    - 귓속말은 괜한 오해를 불러일으킴
    - 차라리 종이에 써서 소통하는게 나음
  - 협상 테이블에서 적극적 거짓말하는 하는 것
    - 적극적 거짓말: A인데 B라고 주장하는 것
    - 소극적 거짓말: A인데 A라고 정확히 밝히지 않는 것
    - 상대가 나에게 불리한 정보를 묻더라도 절대 적극적 거짓말을 하면 안됨 -> 말할 수 없는 입장이라면 침묵하는게 나음

- 코드 리뷰 상황
 "이 코드 왜 이렇게 짰어요?" vs "이 부분 읽을 때 흐름이 잘 안 잡혔어요."

* 주어가 다릅니다. 전자의 숨은 주어는 "당신"(당신이 왜 이렇게 짰나)이고, 후자는 "나"(내가 읽을 때)입니다. 17강 표현대로 하면 전자는 상대를 판단하는 언어, 후자는 내 감정·경험을 전달하는 언어죠.

* 반박 가능성이 다릅니다. "왜 이렇게 짰어요"는 "이렇게 짠 게 잘못됐다"는 전제가 깔려 있어서 상대가 방어부터 하게 됩니다. 반면 "내가 읽을 때 안 잡혔다"는 사실 자체를 반박할 수 없습니다. 내 경험이니까요. 그래서 상대가 방어 대신 "아, 그럼 이렇게 바꿀까요?"로 넘어가기 쉽습니다.

* 정보량이 다릅니다. 후자는 "가독성에 문제가 있다"는 구체적 진단을 담고 있는데, 전자는 불만만 있고 무엇이 문제인지 없습니다.

# 18. 우리 딸이 갈소원보다 예쁜 이유
- 상대가 이성적으로 완벽해도, 뭔가 내 감정을 거슬리면 그 협상은 어려워짐
- 협상 테이블에서 상대가 나에 대해 좋은 감정을 갖게 하는 방법
  - 미러링 원리를 활용하는 것
    - 상대에게 내가 그와 비슷한 사람이라는 동질감을 심어줘 호감을 극대화 하는 방법
    - 나에 대한 소개를 상대의 입장에 맞게 소개
      - 정주영 회장이 소련에서 열심히 일해서 돈을 번 '부유한 노동자' 라고 소개
      - 미셸 오바마 여사가 중국에서 가장 '중국다운'색의 붉은 드레스를 입고 다닌 것
- 사람이 어떤 의사결정을 할 때는 사실도 물론 중요하지만, 감정이 궁국적으로 더 큰 영향을 미침

# 19. 이슈는 미워해도 사람은 미워 마라
- 협상 상대와의 좋은 관계를 맺는 두번째 방법은 이슈와 인간 관계를 분리하는 것
  - 상대가 자꾸 거짓말을 하고 무례하게 말하면? 화를 내서 표현 vs 포커페이스 유지
    - 상대에게 표현하는 것이 더 좋음 -> 나중에 쌓이면 한번에 터짐
    - 화를 내더라도 `이슈에 대해선 강하게 얘기하더라도 인간관계는 부드럽게 가져가라`
      - '우리 입장은 이건데, 너희 입장은 뭐냐?' 보단 '선배인 당신으로부터 많은 것을 배우고 싶습니다. 해결책에 대한 묘안으로 뭐가 있을까요'
- 협상이란 서로 간의 첨예한 요구가 부딪히는 행위 -> 마냥 행복한 감정을 가질 수 없음
  - 인간 관계까지 무너지면 다시 만날 수 있는 다리가 완전히 끊겨버림

# 20. 사악한, 그래서 알아야 하는
- 포커와 협상의 공통점은?
  - 자기 나름의 베팅 원칙이 있어야함
  - 상대를 알아야 함
    - 상대의 게임 스타일이나 상대가 즐겨 쓰는 거짓 수법을 파악해낼 수 있어야 허무하게 지지 않음
- 대표적인 거짓 술책(사술) 세가지
  - 스트레스 기법
    - 상대의 평정심을 깨뜨려 이성적 판단을 하지 못하도록 하는 것
    - 이 지옥 같은 협상장에서 빨리 벗어나고 싶어지도록 만들어 더 많은 양보를 얻어내는 것
      - 중국 협상단이 담배를 계속 피우고, 투명한 잔에 가래침을 뱉는 등으로 상대가 와전 질려버리게 함
      - 일부러 에어컨이 고장 난 방으로 섭외
      - 볼펜을 딱딱거리며 신경 쓰이게 하는 것
  - 굿 가이 배드 가이
    - 대조 효과
      - 협상 테이블에서 아주 무리한 요구를 하는 나쁜 상대과 나의 말을 조금이라도 들어주면 착한 사람으로 인식
    - 협상 테이블에선 굿 가이를 조심해야함
      - 배드 가이가 던지는 말은 굿 가이의 말을 돋보이게 하기 위한 미끼일 가능성 존재
  - 니블링(nibbling)
    - '뭔가를 야금야금 씹다'라는 의미로 협상의 마지막 순간에 작은 것을 요구해 얻어내는 기법
      - 손님이 2시간동안 옷을 몇 벌 입어보고, 닫기 10분전에 양복을 사면서 "비싼 양복 사는데. 넥타이 하나 서비스로 주시죠"
        - 넥타이를 전반적으로 줌 -> 이사람한테 들인 노력에 대한 매몰비용
    - `상대가 니블링을 쓰면 역니블링으로 대응`
      - "넥타이에는 셔츠가 딱인데 셔츠를 사시면 넥타이를 드릴께요"
- 사술을 알고 있어 당하지 않는 것이 중요

# 21. 덜 사악한, 하지만 알아야 하는
- 사술은 공격할 때 쓰는 기술
- 협상에서 방어적으로 쓰기 좋은 '덜 사악하지만' 알아두면 도움되는 두가지 기법
  - 플린칭(flinching)
    - 상대에 요구에 대해 '깜짝 놀라는 반응 '(움찔하는 반응) 보이기
    - 사람은 감성의 동물이기에 누군가 내앞에서 청각적, 시각적 반응을 하면 '어이쿠, 이게 아니구나!' 이런 감정이 생김
    - 가장 강력한 플린칭은 상대의 제안을 듣자마자 벌떡 일어서는 것
    - 가장 약한 플린칭은 상대의 말을 그대로 반복하는 것
    - 우리나라에서 플린칭을 잘 안쓰는 이유는? 체면 때문에
  - 권한 위임
    - 내가 권한을 갖고 있지만, 내가 최종 결정권자가 아니라고 발을 빼는 기법
      - '죄송한데, 가격을 결정하는 건 제 권한 밖의 일입니다. 본사에 좀 물어본 후 확답을 드려도 될까요?'
    - 효력
      - 시간을 벌수 있음
      - 상대로부터 더 많은 양보를 얻을 수 있음

      - 상대과 관계 단절을 막을 수 있음
        - 계속 만나야하는 사이인데, 계속 거절하면 상대가 나에 대한 나쁜 감정이 생기기 쉬움
- 위의 2가지 기법을 너무 자주 쓰면 안됨
  - 상황이 반복될수록 상대에 대한 신뢰는 허물어짐
- 20강에 기술은 공격적이고 사악하다면, 21강은 방어에 주력하는 기술(가끔 서도 되는 기술)
  - 위에 기술들은 잔기술
